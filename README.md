"ARQUITECTURA DE VIRTUALIZACION EN WINDOWS 11"
PRIMER PUNTO
Uno de los puntos que se menciono en el trabajo es dar una explicacion de que impacto generan las funciones de seguridad con la virtualizacion en el famoso Windows 11 y tras un rato investigar llegue a la conclusion de que el Aislamiento de Núcleo y la Seguridad basada en Virtualización (VBS) son pilares de la arquitectura de seguridad de Windows 11. Aunque ofrecen una protección robusta contra ataques de nivel de kernel, su funcionamiento altera profundamente cómo el sistema operativo interactúa con el hardware y otros programas de virtualización
Con esto damos a entender que quizas sea una mayor seguridad pero tendremos limitaciones de Hadware
